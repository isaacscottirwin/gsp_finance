# Graph Signal Processing for Financial Markets

Research-oriented project exploring graph signal processing methods for financial market analysis.

## Topics

- Financial asset graphs

- Spectral graph theory

- Graph Fourier transforms

- Signed market networks

- Spectral energy analysis

- Dynamic market structure

## Structure

- `src/` core implementation

- `notebooks/` exploratory experiments

- `configs/` experiment settings

- `results/` generated figures and outputs

- `docs/` project notes and report material

## Status

Early-stage research and experimentation project.
